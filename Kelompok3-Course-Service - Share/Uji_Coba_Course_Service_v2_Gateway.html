Ini meniru persis 4 uji di laporan Kelompok 1: nama valid, nama tidak ditemukan, service mati (503), dan perubahan port tanpa ubah kode.

Harapan: course hidup → 200, resolved_url sesuai port di atas. Nama sinta → 400. Course mati → 503.

Urutan uji yang disarankan (sama seperti demo)

1. GET semua course → terlihat 2 data awal.
2. POST PTIK303 Basis Data → 201 Created, data bertambah jadi 3.
3. GET detail id 1 → 200 OK, data PTIK301.
4. GET /api/health → 200 OK, status UP (ini yang dicek Kelompok 7).
5. DELETE id 3 → 200 OK, course berhasil dihapus.
6. GET semua course lagi → data kembali jadi 2. Ini bukti DELETE benar-benar bekerja.

Coba juga kasus error: POST dengan code yang sama (409), GET id 99 (404), dan centang "Wajibkan token" lalu uji tanpa token (401).
